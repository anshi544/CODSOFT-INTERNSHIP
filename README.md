# CODSOFT Internship Projects 

This repository contains all the projects completed during the CODSOFT Python Programming Internship using Python and Streamlit.

## Projects Included

### 1️⃣ Smart Calculator Web App
A modern calculator web application with basic arithmetic operations and interactive UI.

### 2️⃣ Secure Password Generator
A password generator with customizable options such as symbols, uppercase letters, numbers, and password strength checker.

### 3️⃣ Smart To-Do Manager
A task management application with task tracking, priorities, progress bar, and interactive controls.

### 4️⃣ AI Rock Paper Scissors
An AI-themed Rock Paper Scissors game with score tracking, match history, and dynamic gameplay.

### 5️⃣ Smart Contact Book Manager
A contact management system with add, search, delete, and interactive contact display features.

# Technologies Used

- Python
- Streamlit
- Pandas
- GitHub
- Streamlit Community Cloud
