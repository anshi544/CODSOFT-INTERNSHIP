# Smart Contact Book Manager

A contact management web application built using Python and Streamlit.

## Features
- Add contacts
- Search contacts
- Delete contacts
- Interactive table display
- Dynamic filtering
- Modern UI

## Technologies Used
- Python
- Streamlit
- Pandas
